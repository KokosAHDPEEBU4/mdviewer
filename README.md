# MD Viewer

Быстрый просмотрщик Markdown для Windows: PyQt6 + mistune, тёмная и светлая
тема, самодостаточная сборка без установленного Python, установщик и
портативная версия.

## Возможности

- две темы: тёмная в духе QuickLook (по умолчанию) и светлая; переключение —
  в диалоге «Настройки» (ПКМ по вкладке → «Настройки…» или `Ctrl+,`), выбор
  запоминается и применяется ко всем открытым окнам и вкладкам сразу, включая
  системный заголовок окна; обе темы красят колонку текста, код, цитаты,
  таблицы (включая чередование строк), task lists, сноски и определения;
- оглавление слева: разделы с отступами по уровням, текущий раздел подсвечивается
  при прокрутке, клик переходит к разделу (`Ctrl+B` скрывает/показывает); строка
  «Фильтр…» над списком прячет несовпадающие разделы (регистронезависимо), `Esc`
  в поле очищает фильтр;
- «хлебные крошки» над превью показывают путь заголовков текущего раздела
  (`# → ## → …`); клик по сегменту возвращает к этому заголовку;
- всплывающая панель управления: появляется при наведении на окно и содержит
  оглавление, режим правки, поиск, открытие файла и масштаб;
- локальные картинки (`![](img/a.png)`) подставляются из папки документа,
  внешние ссылки открываются в браузере;
- ссылки на другие `.md`/`.markdown`/`.txt` открываются в этом же окне с полным
  оформлением, кнопка «←» в панели (или `Alt+Left`) возвращает в предыдущий файл;
  обычный клик навигирует текущую вкладку, `Ctrl`+клик (или средняя кнопка) —
  открывает новую;
- вкладки: одно окно держит несколько файлов; вкладки переставляются
  перетаскиванием по полосе, а если вытянуть вкладку вниз из полосы — она
  отрывается в отдельное окно (как в браузере); бросок на чужую полосу
  вставляет её на место, бросок на другое окно сливает вкладки;
  `Ctrl+O` открывает несколько файлов, `Ctrl+W` закрывает вкладку,
  `Ctrl+Shift+T` возвращает последнюю закрытую, `Ctrl+Tab`/`Ctrl+1..9`
  переключают; зум по умолчанию, светлая тема и восстановление прошлой сессии —
  в диалоге «Настройки» (`Ctrl+,`), по умолчанию 100%, тёмная тема и выключено;
- ПКМ по вкладке: «Открыть содержащую папку», «Копировать путь» (действуют на
  вкладку под курсором, иначе на активную), подменю «Недавние» — до 10
  последних открытых файлов (свежие впереди, без повторов) с пунктом «Очистить
  список» — и «Настройки…» (единый диалог, см. ниже);
- экспорт вкладки через ПКМ → «Экспорт»: «PDF…» печатает текущее превью в PDF
  (`QPrinter`, высокое разрешение, поля страницы 15 мм; реальный принтер не
  нужен), «HTML…» сохраняет самодостаточную страницу с текстом документа,
  встроенным CSS текущей темы, `<meta charset="utf-8">` и заголовком по имени
  файла; локальные картинки остаются абсолютными `file:`-ссылками, сетевые
  ресурсы не запрашиваются; отмена диалога ничего не записывает;
- один экземпляр приложения: двойной клик по `.md` (или запуск exe с файлом)
  открывает вкладку в уже запущенном окне, а не новое окно;
- поиск `Ctrl+F` (по активной панели: редактор в правке, иначе превью) и
  поиск с заменой `Ctrl+H` в редакторе — при необходимости сам входит в правку
  и показывает поле «Заменить на» с кнопками «Заменить»/«Заменить все»
  (пустой запрос игнорируется); перезагрузка `F5`, масштаб
  `Ctrl`/`+`/`-`/`0` (клик по «100%» переключает 100% ↔ 200%);
- следит за файлом на диске: если файл изменили в другой программе, превью
  перечитывается само, сохраняя позицию чтения; при несохранённых правках
  приложение сначала спрашивает, перезагрузить ли файл и потерять их; удаление
  или переименование файла не рушит открытый документ и снимает наблюдение;
- черновики несохранённых правок переживают падение: текст автоматически
  копируется на диск через 3 секунды после последнего изменения (и перед
  выходом из приложения), а при следующем открытии файла приложение
  предлагает его восстановить (`Да` — войти в правку с текстом черновика,
  `Нет` — удалить); черновик удаляется после сохранения или отказа от правок,
  хранится в каталоге состояния (`%LOCALAPPDATA%\MDViewer\drafts`,
  переопределяется `MDVIEWER_STATE_DIR`);
- режим чтения `F11`: полный экран без полосы вкладок, оглавления и панели
  управления — только текст; повторное `F11` или `Esc` возвращает обычное окно;
- режим правки: `Ctrl+E` открывает справа исходный Markdown (окно расширяется,
  колонки делит `QSplitter`), кнопки «Конвертировать» (`Ctrl+Enter`) и
  «Сохранить» (`Ctrl+S`); после сохранения превью обновляется само,
  `•` в заголовке означает несохранённые изменения, `Esc` выходит из правки;
  выделение синхронизируется между исходником и превью (карта позиций),
  цвета накладываются друг на друга при пересечении; перенос строк (вкл по
  умолчанию), номера строк (выкл по умолчанию) и синхронизация прокрутки (вкл
  по умолчанию) переключаются в диалоге «Настройки» и применяются сразу;
  прокрутка одной панели подтягивает другую по карте позиций
  (или по заголовку раздела), без петель и лишних перерисовок;
- кодировка и переводы строк исходного файла сохраняются при записи
  (utf-8 с/без BOM, utf-16, cp1251, LF или CRLF);
- системный заголовок окна подстраивается под тему: тёмный для тёмной,
  светлый для светлой (`DwmSetWindowAttribute`);
- запоминает размер/положение окна и папку последнего открытия; при закрытии
  из режима правки сохраняется геометрия окна просмотра, а не расширенного;
- в заголовке окна всегда видно `— MD Viewer <версия>`: видно, какая сборка
  запущена;
- не пересобирает HTML при изменении размера окна (ширина колонки задаётся
  отступами `QTextBrowser`, а не CSS) — resize крупного файла стоит ~14 мс
  вместо ~236 мс; оглавление строится в том же проходе, что и рендер
  (+~40 мс на 500 заголовков), а позиции разделов считаются лениво.

## Настройки

Все настройки собраны в одном диалоге — «Настройки…» в ПКМ-меню вкладки или
оконный хоткей `Ctrl+,`:

- тема: тёмная (по умолчанию) или светлая — применяется ко всем открытым окнам
  и вкладкам сразу, включая системный заголовок;
- масштаб по умолчанию новых вкладок: 80/90/100/110/120/150/200 % (уже открытые
  вкладки не трогаются);
- восстанавливать прошлую сессию (то же, что CLI `--restore-session`);
- перенос строк в редакторе (вкл по умолчанию);
- номера строк в редакторе (выкл по умолчанию).

Парная прокрутка редактор ↔ превью включается на месте: в режиме правки
`Alt`+колесо над одной панелью подтягивает вторую к тому же месту (по карте
позиций). Обычное колесо панели не связывает — это не настройка по умолчанию.

Кнопки «ОК»/«Отмена»: изменения применяются по «ОК» и сохраняются в `QSettings`.
Разрозненные пункты ПКМ-меню («Светлая тема», «Восстанавливать прошлую сессию»,
«Масштаб по умолчанию») и меню «⋯» редактора удалены — единый источник теперь
этот диалог.

## Запуск из исходников

```bash
py -3.14 -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python main.py README.md
```

## Сборка

Требования: Windows 10/11, Python **3.14** (подойдёт и 3.10+), интернет для
установки зависимостей. Всё остальное делает `build.bat`.

```bash
git clone https://github.com/KokosAHDPEEBU4/mdviewer.git
cd mdviewer
build.bat
```

`build.bat` по шагам:
1. создаёт `.venv` (если его нет) и ставит `requirements.txt` + PyInstaller;
2. чистит `build\` и `dist\` — это обязательно: старые `pythonXXX.dll` иначе
   попадают в сборку и приложение падает с «не найден python310.dll»;
3. собирает `PyInstaller --clean MDViewer.spec`.

Результат — `dist\MDViewer\MDViewer.exe` рядом с папкой `_internal\` (свой
интерпретатор `python314.dll` и Qt; Python на машине не нужен).

```bash
dist\MDViewer\MDViewer.exe README.md   # запустить собранное
build.bat --run                        # собрать и сразу зарегистрировать .md
```

Проверка свежести сборки: в `dist\MDViewer\_internal\` есть `python314.dll` и
**нет** `python310.dll`.

## Установщик

`build-installer.bat` оборачивает готовый `dist\MDViewer` в инсталлятор Inno
Setup — `dist\MDViewer-Setup-<версия>.exe` (ярлыки в меню «Пуск» и на рабочем
столе, пункт «сделать `.md` по умолчанию», корректный деинсталлятор).

```bash
build.bat            # сначала сама сборка (если dist ещё нет — соберётся сам)
build-installer.bat  # затем инсталлятор
```

Требуется **Inno Setup 6** (https://jrsoftware.org/isinfo.php); скрипт ищет
`ISCC.exe` в `Program Files (x86)\Inno Setup 6`.

## Релизы (установщик в GitHub Releases)

Установщик собирается автоматически в CI по тегу — локальные Inno Setup и `gh`
не нужны:

```bash
# поднимите версию в version.py, закоммитьте, затем:
git tag v2.6.0
git push mdviewer master --tags
```

Workflow `.github/workflows/release.yml` на `windows-latest` собирает приложение,
делает инсталлятор через Inno Setup и публикует в **Releases** два файла:
`MDViewer-Setup-<версия>.exe` и `MDViewer-portable.zip`. Версия файла берётся из
`version.py`.

## Ассоциация с .md

```bash
dist\MDViewer\MDViewer.exe --install-default
```

Приложение копируется в `%LOCALAPPDATA%\Programs\MDViewer`, регистрируется в
`HKCU\Software\Classes` (ProgID `MDViewer.MarkdownFile`, иконка, команда,
`OpenWithProgids`, `RegisteredApplications`) и открывает системный диалог
«Открыть с помощью» — там нужно один раз нажать «Всегда».

Назначить обработчик по умолчанию напрямую нельзя: ключ
`...\Explorer\FileExts\.md\UserChoice` принадлежит Explorer, и обычный процесс
не может его открыть на запись (`WinError 5`), несмотря на корректный hash.

Проверка и откат:

```bash
dist\MDViewer\MDViewer.exe --assoc-status
dist\MDViewer\MDViewer.exe --uninstall-default
```

## Структура

```

instance.py    single-instance: мьютекс Win32 + очередь запросов
viewer.py      DocumentView (файл: превью, оглавление, редактор, оверлей,
               поиск, подсветка, наблюдение за файлом, экспорт в HTML/PDF)
               + MainWindow (QTabWidget, заголовок, геометрия, tear-off/merge,
               ПКМ-меню вкладок) + TabBar + совместимый Viewer
drafts.py      черновики несохранённых правок на диске: save/load/clear/pending
               в каталоге состояния (sha1-имя, JSON: путь/текст/время)
renderer.py    mistune -> HTML (код, картинки, чекбоксы, якоря заголовков)
theme.py       палитры (тёмная/светлая), CSS для Qt rich text, размеры колонки,
               QSS приложения
winassoc.py    регистрация обработчика .md в HKCU
version.py     версия, имя, ProgID, расширения
MDViewer.spec  PyInstaller: onedir, иконка, версия, вырезание лишнего Qt
build.bat      venv + зависимости + PyInstaller, флаг --run
build-installer.bat  оборачивает dist\MDViewer в Inno Setup инсталлятор
installer/     MDViewer.iss — сценарий Inno Setup
.github/       workflows: ci.yml (py_compile) и release.yml (тег -> релиз)
tools/         make_icon.py (генерация assets/icon.ico), render_check.py,
               debug_html.py (быстрый просмотр HTML),
                edit_check.py (правка/оглавление/оверлей/перезагрузка с диска,
                черновики: автосейв/восстановление),
                tabs_check.py (вкладки: дедуп, закрытие, tear-off/merge,
                наблюдение за файлом)
```

## Ограничения Qt, на которые заточен код

`QTextBrowser` понимает лишь подмножество CSS: не работают переменные,
`max-width`, `margin: auto`, `padding`/`border` у блочных элементов,
`::before`, переходы. Поэтому отступы колонки задаются через
`viewport().setContentsMargins()`, а блоки кода — обычный `<pre class="code-body">`
(отступ слева даёт `text-indent`, т.к. `padding` у `<pre>` Qt игнорирует).
Таблица приложения должна быть установлена до первого `setHtml()`, иначе Qt
не применит стили к документу.

Второй подвох Qt — `QPlainTextEdit.toPlainText()` всегда возвращает текст с
`\n`, даже если в файле `\r\n`. Поэтому сравнение «правился ли файл»
(`viewer._baseline`, `viewer._rendered`) идёт через `viewer._normalized()`,
а не напрямую с `read_document()`.
