Начало работы

Слева — файлы папки текущего документа. Одиночный клик открывает файл в этой же вкладке (с историей «Назад»), Ctrl+клик / двойной клик — новой вкладкой. Точка «•» — файл уже открыт во вкладке.

Вкладки остаются для файлов из разных папок: внутри одной папки переключаемся панелью, «лишние» папки закрепляем вкладками.

M просматриваемый (.md/.txt) ▢ прочий файл (клик → системное открытие) • уже открыт во вкладке строка активный файл пунктир на согласование

1 · По умолчанию скрыта

Окно выглядит как сейчас: оглавление + превью. Панель вызывается хоткеем (предложение: Ctrl+Shift+E) или пунктом «Панель файлов» в ПКМ-меню вкладок. Видимость и ширина запоминаются.

2 · Следует за активной вкладкой

Активировали вкладку из другой папки — панель показывает её папку. Так вкладки = «закреплённые» файлы из разных мест, панель = навигация внутри текущей папки.

3 · Перетащить во вкладки

Файл из панели тащится на полосу вкладок — открывается вкладкой в позиции курсора. Панель при этом остаётся на старой папке, пока активна текущая вкладка.
