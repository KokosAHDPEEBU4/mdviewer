# AGENTS.md — как работать с проектом MD Viewer

Настольный просмотрщик Markdown для Windows. **UI:** PyQt6 (`QTextBrowser`),
**рендер:** mistune, **сборка:** PyInstaller onedir. Код Python 3.10+,
целевая среда — Windows.

## Структура

```
main.py         CLI (файлы, --install-default/--uninstall-default/--assoc-status/
                --restore-session), QApplication, диалог открытия файла; создаёт
                один MainWindow, CLI-пути открываются вкладками; единственный
                экземпляр — второй запуск отдаёт пути через instance.py
instance.py     single-instance: именованный мьютекс Win32 + файловая очередь
                запросов (QtNetwork вырезан из сборки, QLocalServer недоступен)
viewer.py       DocumentView(QWidget) — содержимое одного файла: превью
                (контейнер «крошки + QTextBrowser») + оглавление с фильтром +
                QPlainTextEdit, оверлей, поиск (Ctrl+F) и замена (Ctrl+H),
                синхронизация прокрутки редактор ↔ превью, подсветка, zoom,
                история, QSettings, dirty-state, режим чтения,
                QFileSystemWatcher (автоперезагрузка при изменении файла
                на диске);
                MainWindow(QMainWindow) — оболочка: QTabWidget, заголовок,
                геометрия, режим чтения (F11), closeEvent по всем вкладкам,
                реестр _WINDOWS;
                TabBar(QTabBar) — tear-off/merge вкладок; совместимый
                Viewer(MainWindow) для tools/
renderer.py     mistune -> HTML: код, картинки, чекбоксы, сноски, якоря заголовков
                и оглавление (render_with_outline)
theme.py        палитра, CSS для Qt rich text, MEASURE/side_margin, QSS приложения
syncsel.py      SourceMap: выравнивание источник <-> рендер для синхронизации выделения
winassoc.py     регистрация .md в HKCU (ProgID, OpenWithProgids, RegisteredApplications)
version.py      APP_NAME, APP_VERSION, PROG_ID, EXTENSIONS — общий источник истины
MDViewer.spec   PyInstaller: иконка, версия, excludes, вырезание лишнего Qt
build.bat       venv + pip + PyInstaller, флаг --run
tools/          make_icon.py, render_check.py, debug_html.py, edit_check.py,
                tabs_check.py
```

## Команды

```bash
.venv\Scripts\python main.py README.md          # запуск из исходников
build.bat                                       # сборка dist\MDViewer
.venv\Scripts\python tools\render_check.py      # визуальная проверка темы
.venv\Scripts\python tools\edit_check.py        # правка/конвертация/сохранение,
                                                # оглавление, оверлей
.venv\Scripts\python tools\tabs_check.py        # вкладки: дедуп/закрытие,
                                                # tear-off/merge, сессия
.venv\Scripts\python -m py_compile *.py
```

## Инварианты (НЕ нарушать)

1. **Qt rich text поддерживает подмножество CSS.** Не работают: CSS-переменные,
   `max-width`, `margin: 0 auto`, `padding`/`border` у блочных элементов,
   `::before/::after`, переходы, внешние CSS-файлы. Любое новое оформление
   сначала проверяй рендером: `tools/render_check.py` (цвета) или
   `tools/debug_html.py` (структура HTML).

2. **Ширина колонки — через `QTextBrowser.viewport().setContentsMargins()`**
   (`theme.side_margin`, `viewer.Viewer._set_margins`), а не через CSS: пересборка
   HTML на каждый resize стоила ~236 мс, отступы — ~14 мс. HTML собирается один
   раз в `Viewer.load()`.
   Политика: узкое окно отдаёт ширину тексту (отступ `GUTTER_MIN`=20),
   колонка растёт максимум до `MEASURE`=1300 px, дальше лишнее уходит в
   симметричные поля (на окне 1700 — по 200 px, на 3440 — по 1072 px).
   Пересчитывать отступы нужно **и** при `QSplitter.splitterMoved`: правка
   колонки не вызывает `resizeEvent` у окна, иначе в превью остаются поля,
   посчитанные для старой ширины. Политика закреплена в `tools/edit_check.py`.
   Ширина `<img>` от неё не зависит — это отдельный `IMAGE_MAX`.

3. **Блоки кода — обычный `<pre class="code-body">`, БЕЗ таблицы.**
   (`renderer._code_block`.) Раньше код оборачивался в одноячейковую таблицу
   ради `padding` (у `<pre>` Qt его игнорирует), но у Qt **сломан hit-testing в
   многострочной ячейке таблицы**: клик между строками кода возвращал *последнюю*
   строку блока, поэтому выделение «начиналось с низа», а `cursorForPosition`
   (поиск раздела, вставка каретки) указывал не туда. `<pre>` хит-тестится
   верно; отступ слева даёт `text-indent` (Qt его уважает, в отличие от
   `padding`), вертикальный воздух — leading от `line-height`, а язык — отдельный
   `<p class="code-lang">` с тем же фоном (`pre.code-body.has-lang` убирает
   зазор между ними). НЕ возвращай таблицу для кода.

   Регулярка `_CODE_BLOCK` обязана захватывать `</code>` в группу: если оставить
   его вне группы, в вывод попадёт «висячий» закрывающий тег.

   **Размеры шрифта в `content_css` — только в `em`/относительные**, иначе
   `QTextBrowser.zoomIn` их не масштабирует (инлайн-код раньше был `13.5px`
   и «не приближался»). Данные-таблицы: mistune выдаёт `th`/`td` без `<tr>`,
   поэтому `renderer._table_rows` перегруппировывает ячейки в строки по числу
   колонок шапки, проставляет `border="1"` (Qt рисует сетку только из атрибута)
   и `bgcolor` с чередованием (`:nth-child` не поддерживается).

4. **`mistune` работает с `escape=False`.** Это приложение для локального
   просмотра файлов; включай новые плагины только если проверишь, что они не
   ломают вывод (см. список плагинов в `renderer.py`).

5. **Никаких сетевых запросов и внешних ресурсов.** Ссылки открываются через
   `QDesktopServices`, картинки — только локальные (`file:` URI), ширина
   ограничивается через `QImageReader`.

6. **Ассоциацию .md нельзя выставить программно.** Ключ
   `HKCU\...\Explorer\FileExts\.md\UserChoice` открывается на чтение, запись
   даёт `WinError 5` — Explorer пишет его сам, только после действия
   пользователя (`SHOpenWithDialog` или «Параметры → Приложения по умолчанию»).
   `winassoc.install()` регистрирует всё остальное и открывает диалог; ключ
   с hash из старых версий проекта удалён — не возвращай его.

7. **Сборка только из `.venv` и всегда чистая.** `--clean` обязателен: старые
   артефакты `python310.dll` от прошлых сборок иначе попадут в `dist` (именно
   это вызывало ошибку «не найден python310.dll»). Проверяй результат:
   `dist\MDViewer\_internal\python314.dll` есть, `python310.dll` — нет.

8. **Собирай версию из объекта `VSVersionInfo`**, не из словаря: PyInstaller
   6.22 отклоняет dict (`TypeError: Unsupported type for version info
   argument`). Структура собирается в `MDViewer.spec` из
   `PyInstaller.utils.win32.versioninfo`.

9. **`create_app()` обязан быть присвоен переменной** (`app = create_app()`).
   Если не удержать ссылку, CPython сразу уничтожит `QApplication`, и следующий
   же `QWidget` уронит процесс с `0xC0000409` — без traceback и вывода.

10. **`QPlainTextEdit.toPlainText()` отдаёт только `\n`.** Сравнивать его с
    результатом `read_document()` нельзя: для CRLF-файла «правка» будет
    считаться всегда. Базовая линия редактора — `viewer._normalized(text)`,
    она же лежит в `_baseline` и `_rendered`.

11. **Определение кодировки в `read_document()`** опирается на BOM, а не на
    порядок проб. `utf-16` успешно декодирует любой байтовый массив чётной
    длины, поэтому в `_candidate_encodings()` он идёт после `utf-8`/`cp1251`
    и только при наличии BOM или нулевых байтов. Проверяй круг
    «открыть → изменить → сохранить» через `tools/edit_check.py`.

12. **Превью перерисовывается только по явной команде** («Конвертировать»
    или сохранение), а не на каждое нажатие клавиши: рендер файла в ~600 КБ
    занимает ~0.5 с. Состояние режима правки держи флагом `_edit_mode`,
    а не `isVisible()` — иначе сохранение «отваливается» для невидимого окна.

13. **Версия в заголовке — не украшение, а диагностика**
    (`viewer._title()`, `MD Viewer <версия>`): по ней видно, какая копия
    запустилась, когда пользователь жалуется на «старую версию». Проверять
    надо сравнением деревьев: `dist\MDViewer` и
    `%LOCALAPPDATA%\Programs\MDViewer` должны совпадать по sha256 всех файлов.

14. **`closeEvent` в режиме правки сохраняет `_view_geometry`**, а не текущую
    геометрию: иначе закрытие в разделённом режиме оставляет «широкое окно
    без редактора» на следующий запуск — выглядит как сломанная/старая сборка.
    `_view_geometry` — это `QByteArray` из `saveGeometry()`, а не `QRect`:
    у `QRect` нет метода `saveGeometry`, и исключение в слоте PyQt6 убивает
    процесс с `0xC0000409` без traceback.

15. **Оглавление строится тем же проходом, что и рендер.** `render_with_outline`
    вставляет `<a name="md-hN">` в заголовки и возвращает `Heading(level, label,
    anchor)`. Текущий раздел определяется **по курсору вьюпорта**
    (`_current_section_index`: `cursorForPosition` в левый-верхний угол →
    подъём по блокам до анкора `md-hN`), а не по `blockBoundingRect`: те
    смещения устаревают при переносе текста (ресайз, вход в правку).
    `_sync_outline` подсвечивает раздел этим же методом.

    `_enter_edit` запоминает `_edit_anchor` (label видимого раздела),
    `_edit_visible` (текст абзаца у верхней кромки превью) и `_edit_fraction`
    (долю прокрутки внутри раздела) **до** ресайза окна. `_move_editor_to_preview`
    сначала ищет видимый абзац в пределах своего раздела (`_section_blocks` +
    `_plain_key`, сравнение без markdown-разметки и с схлопнутыми пробелами), и
    только потом откатывается к заголовку раздела (`_find_heading_block`) и к
    позиции по доле (`_find_block_at_fraction`). Поиск абзаца обязан быть в
    границах раздела, иначе одинаковый абзац из соседнего раздела победит.
    Порядок важен: `_update_hits` при входе в правку вызывается без `jump=True`,
    иначе остаточный поисковый запрос уводит каретку с выбранного раздела.

16. **Всплывающая панель — дочерний виджет окна**, а не элемент layout:
    `_overlay` живёт поверх сплиттера (`self._overlay.raise_()`), поэтому не
    отнимает место у текста. Первое появление — на `enterEvent` главного окна,
    но при входе/выходе из правки `_show_overlay()` вызывается принудительно:
    иначе панель остаётся над старым положением превью, пока мышь не дёрнется.
    Статусбара в приложении нет, версия только в заголовке.

17. **Вход в правку не перекраивает превью.** `_enter_edit` запоминает
    `_preview_width = self._browser.width()` **до** `_build_editor()`: добавление
    даже скрытой панели в `QSplitter` сразу отдаёт ей место и сжимает превью.
    Окно растёт до `toc + preview + EDITOR_PREF` (+ ручки), но **не шире экрана,
    на котором окно** (`self.screen()`, не `primaryScreen()` — на нескольких
    мониторах primary мог быть другой), с запасом `* 0.96`. Раскладка — общая
    политика сжатия (`_relayout`, инвариант 25): превью — остаточная панель,
    редактор при нехватке уступает первым, поэтому превью остаётся на месте.
    Курсор редактора ставится на раздел, видимый сейчас в превью
    (`_move_editor_to_preview`), а не в конец файла; сопоставление идёт по тексту
    заголовка, т.к. HTML и markdown не совпадают по смещениям. Каретка
    **не центрируется** (`centerCursor` показывал выше ненужные 3/3.2): после
    `setTextCursor` вызывается `centerCursor()` (он заставляет редактор
    разложиться), затем цель поднимается к верху на
    `cursorRect().top() / fontMetrics().lineSpacing()` строк — **вертикальный
    скроллбар `QPlainTextEdit` считает строки, а `cursorRect` в пикселях**, и
    читать `blockBoundingRect` сразу после `setPlainText` нельзя (раскладки ещё
    нет, все top = 0, и вид остаётся на первой строке). Приоритетный раздел —
    тот, что пользователь выбрал в оглавлении (`_remembered_section`, пока его
    заголовок виден), иначе раздел на верхней кромке вьюпорта.

    `_enter_edit` также запоминает символ на верхней кромке превью
    (`_preview_anchor`): раскрытие редактора чуть сжимает колонку превью
    (окно упирается в экран), документ с таблицами переразбивается, и прежний
    пиксель скролла попадает в другой раздел — читателя «перекидывало»
    (например, с 5-й главы на 3.5). `_relayout` после `_set_margins`
    восстанавливает позицию (`_restore_preview_anchor`), якорь снимается через
    200 мс и при выходе из правки.

18. **Никаких всплывающих подсказок с хоткеями.** Кнопки оверлея и поиска
    намеренно без `setToolTip`: подсказки «Ctrl+E/F/B» постоянно выскакивали
    поверх текста и мешали. Хоткеи остаются в работе, но не описываются
    всплывающими окнами.

19. **Зум раздельный у всех трёх панелей.** `_zoom` (превью), `_editor_zoom`
    (исходник) и `_toc_zoom` (оглавление) независимы. `Ctrl+колесо` над панелью
    зумит именно её через `_wheel_zoom`: `eventFilter` стоит и на панелях, и на
    их `viewport` (`_pane_for`). Qt доставляет колесо и мышь во viewport
    scroll-area, а не в сам виджет; фильтр только на виджете пропускал
    встроенный зум `QTextBrowser` — шрифт ехал, а `_zoom` и метка застывали на
    «100%». Дельта колеса накапливается (`WHEEL_STEP`), `pixelDelta`
    тачпада и `angleDelta` мыши приводятся к одной единице — иначе мелкие
    события тачпада давали ступень на каждый пиксель. `Ctrl+=/-/0` — панель в
    фокусе (`_zoom_step`). При входе в правку редактор открывается на текущем
    зуме превью (`_set_editor_zoom(self._zoom)`), дальше зумы независимы.
    `_set_editor_zoom`/`_set_toc_zoom` меняют шрифт; «100%» в шапке редактора
    сбрасывает только редактор. `QFont` мутабельный: копировать перед
    `setPointSizeF`, иначе базовый шрифт панели портится. Смена шрифта превью
    переразбивает документ, поэтому `_set_zoom` запоминает символ на верхней
    кромке вьюпорта и возвращает его туда после зума (`_scroll_preview_to`) —
    иначе при Ctrl+колесе картинка «пролистывалась». Интерфейс — на русском.

20. **Ширина оглавления перетаскиваемая.** Нельзя `setFixedWidth` у `_toc`
    (это ставит min=max и ломает и минимум `TOC_MIN_WIDTH`, и ручную ширину) —
    ширина задаётся через `QSplitter.setSizes` в `_relayout`, а пользовательская
    сохраняется в `QSettings("toc_width")` из `_on_splitter_moved` (вместе с
    `_editor_pref` — см. инвариант 25). Ширина ручки сплиттера — `SPLIT_HANDLE`
    = 14 px (`setHandleWidth`): за границу панелей проще зацепиться мышью, чем за
    ~5 px по умолчанию; под курсором ручка подсвечивается
    (`QSplitter::handle:hover` в `APP_QSS`). `_relayout` **вычитает**
    `SPLIT_HANDLE * (panes - 1)` из бюджета, иначе ручки съедают ширину и
    превью/редактор расходятся с задуманным. `setSizes` индексирует **всех
    детей, включая скрытых**, поэтому список всегда полный (0 для скрытой
    панели) — иначе ширины попадают не на те виджеты.

21. **Автоскролл средней кнопкой — на панель.** `eventFilter` ловит
    `MiddleButton` на панели **и её `viewport`** (событие приходит во viewport),
    у viewport включён `setMouseTracking(True)` — иначе движения без нажатой
    кнопки не доставляются. `ScrollIndicator` (дочерний оверлей
    с `WA_TransparentForMouseEvents`) рисует кольцо, `QTimer`(16 мс) двигает
    `verticalScrollBar` выбранной панели по `_autoscroll_offset` с мёртвой зоной
    `SCROLL_DEAD_ZONE`. Останавливается Esc, повторным средним кликом, обычным
    кликом или колесом. Панели независимы: скролл одной не трогает другую.

23. **Оглавление переносит длинные заголовки.** `_toc.setWordWrap(True)` вместе
    с `setUniformItemSizes(False)`: иначе `QListWidget` обрезал заголовок и
    рисовал многоточие (`ElideRight`). Заголовок целиком остаётся и в
    `setToolTip`.

24. **Ссылки на другие .md открываются в этом же окне, с кнопкой «Назад».**
    `_browser.setOpenLinks(False)` отключает штатную обработку Qt: иначе она
    либо делала `setSource` сырого markdown без темы (пользователь видел
    «базовое оформление»), либо отдавала файл другой программе. Все клики идут
    через `_open_link`. В `_render` документу ставится `baseUrl` текущего файла,
    поэтому относительные ссылки (`other.md`, `#anchor`) разрешаются. Локальный
    markdown/текст (`_viewable`) → `_navigate` с историей `_history`; прочие
    локальные файлы, `http(s)`, `mailto` → `QDesktopServices`; битая ссылка
    игнорируется. Кнопка «←» в оверлее и `Alt+Left` листают историю назад
    (`_go_back`), кнопка неактивна при пустой истории (`_update_nav`). `load()`
    теперь возвращает `bool`: `_load_path` восстанавливает прежний путь, если
    пользователь отменил диалог о несохранённых правках.

22. **Выделение взаимно подсвечивается между панелями.** Цвет кодирует панель,
    где выделение начали: `PREVIEW_SELECTION` оранжевый, `EDITOR_SELECTION`
    бирюзовый (`theme.py`, `QSS` `selection-background-color`). Механика —
    **слои**: `_hl_layers` хранит на панель список `(owner, cursors, colour)`, и
    `_set_hl_layer` заменяет слой своего owner'а и переносит его в конец (самый
    свежий — последний). Более ранний выбор соседней панели **остаётся снизу**
    (не стирается).

    **Ключевой факт Qt (проверено рендером): нативное выделение рисуется ПОВЕРХ
    `extraSelections`**, а не наоборот (z.ai утверждал обратное — неверно для
    Qt 6.11). Поэтому зеркало, показанное только через `setExtraSelections`,
    пряталось под собственным выделением панели. Свежее зеркало дорисовывается
    вручную: `_OverlayMixin` (подклассы `OverlayTextBrowser`/`OverlayPlainTextEdit`)
    вызывает `_paint_selection_overlay` в `paintEvent` ПОСЛЕ `super()`, поверх
    всего, с `HL_OVERLAY_ALPHA` (текст остаётся читаемым). Рисуется только
    последний слой и только если он — зеркало соседней панели (собственное
    выделение и так нативное, поверх). `extraSelections` всё ещё несут цвет
    текста (белый) и старые слои (они корректно под нативным).

    Соответствие позиций — **карта `syncsel.SourceMap`** (источник ↔
    `browser.document().toPlainText()`), построенная лениво на первый выбор
    (`_ensure_map`, сбрасывается в `_render`). Карта выравнивает тексты по
    словам (`\w+`) с ресинком, поэтому переживает снятую разметку, таблицы,
    списки и код, и возвращает точный диапазон — в т.ч. для **многострочных**
    выделений и **дублей** фраз. `toPlainText()`-индексы совпадают с позициями
    документа, так что диапазон идёт прямо в `QTextCursor`. Если карта не
    построилась (сырой HTML) или редактор правили после рендера (`_map_dirty`) —
    откат на поиск по словам с границей раздела (`_match_pattern` +
    `_section_bounds`). И зеркало, и собственное выделение режутся **по блокам**
    (`_range_cursors`, `_own_cursors`): один курсор, пересекающий ячейки таблицы,
    Qt расширяет до целых ячеек и рисует как cell-range — зеркало зажигало всю
    таблицу (включая шапку), а собственный слой перекрывал чужое зеркало.
    `_render` (setHtml) и `_clear_highlights` сбрасывают слои — иначе курсоры
    повисают на пересозданном документе. `_highlight_editor_from_preview` обязан
    выходить, если `self._editor is None`: в режиме чтения редактора нет.

25. **Сжатие окна: политика приоритетов.** Раньше панелями при ресайзе рулил
    `QSplitter` по stretch-факторам, и всё сжатие забирала одна панель (в правке
    превью проваливалось до ~63 px). Теперь `resizeEvent` сплиттера (фильтр в
    `eventFilter`, берём `event.size().width()` — не `window.width()`, и без
    `singleShot`) зовёт `_relayout`. Чистые функции в `viewer.py`:
    `layout_panes(avail, edit, toc_visible, toc_pref, editor_pref)` — при нехватке
    места панели уступают в порядке **TOC → editor → preview**, editor снижается
    через `EDITOR_MIN` до `EDITOR_HARD`, preview — остаточная панель (держит
    `MIN_COLUMN`, пока может, дальше до `PREVIEW_HARD`); и
    `toc_visible_for(main_avail, auto_hidden, user_visible, edit)` — авто-скрытие
    оглавления с гистерезисом (`HYST`), порог считается от `main_avail` (без
    ручек оглавления, чтобы не было петли) и от `TOC_MIN`, **не** от `toc_pref`
    (иначе однажды растянутое оглавление застревало бы скрытым). Два флага:
    `_toc_user_visible` (намерение, в QSettings) и `_toc_auto_hidden` (факт) —
    скрытое пользователем не возвращается само. Ручной drag (`splitterMoved`, не
    программный `setSizes`) обновляет `toc_width` и `_editor_pref`; preview
    своего pref не имеет (см. `EDITOR_PREF` в `theme.py`). Жёсткие `setMinimumWidth`
    (`PREVIEW_HARD`, `EDITOR_HARD`, `TOC_MIN_WIDTH`) — только safety net (и
    минимальный размер окна); панель редактора содержит строку кнопок ~450 px,
    поэтому у `_panel` **обязателен** `setMinimumWidth(EDITOR_HARD)`, иначе её
    layout задирает минимум и редактор не ужимается. Кнопка оглавления
    дизейблится, когда показать его сейчас = сразу спрятать. Трассы —
    тесты `layout_panes`/`toc_visible_for` и «shrink» в `tools/edit_check.py`.

20. **Поиск работает по активной панели** (`_search_target`): в режиме правки —
    по `QPlainTextEdit`, иначе по превью. При входе/выходе из правки счётчик
    пересчитывается (`_update_hits`).

21. **Оверлей строится лениво** (`_ensure_overlay`, отложенно после первого
    кадра). Первый стилизованный виджет прогревает `QStyleSheetStyle` ~300 мс;
    если строить оверлей в `__init__`, окно с текстом появляется заметно позже.
    К `_overlay`, `_find_bar`, `_edit_btn` до постройки обращаться нельзя —
    `_ensure_overlay` вызывается из `_show_overlay`, `_enter_edit`, `_leave_edit`.
    Горячие клавиши (`_build_shortcuts`) создаются в `__init__`, они дешёвые.

26. **Вкладки: одна вкладка = один `DocumentView`, состояние изолировано.**
    `MainWindow` держит `QTabWidget` (`setTabsClosable(True)`, `setMovable(True)`,
    `setDocumentMode(True)`, corner-widget «+» намеренно `None` — вкладки берутся
    только из файлов). Подпись вкладки — `DocumentView._tab_title()` (имя файла +
    ` •` при несохранённых), tooltip — полный путь; дедуп по `Path.resolve()`
    (`_find_tab`) фокусирует уже открытый файл. Страница вкладки — `DocumentView`;
    его зум/правка/история/`_hl_layers`/`_source_map` не «текут» между вкладками.

    - **Хоткеи разведены по контексту.** Per-document (`Ctrl+E/F/B`, `F5`, `Ctrl+S`,
      `Ctrl+Enter`, `Alt+Left`, зум) создаются в `DocumentView._build_shortcuts` с
      `WidgetWithChildrenShortcut`: при `WindowShortcut` две вкладки дали бы
      `Ambiguous shortcut overload`. Оконные (`Ctrl+W`/`Ctrl+Q`/`Ctrl+O`,
      `Ctrl+Shift+T`, `Ctrl+Tab`/`Ctrl+Shift+Tab`, `Ctrl+1..9`) — один раз на
      `MainWindow` (`_build_window_shortcuts`) и маршрутизируются в активную
      вкладку.
    - **Сигналы `DocumentView`:** `state_changed` (перерисовать подпись вкладки и,
      если она активна, заголовок окна) и `link_requested` (Ctrl+клик или средняя
      кнопка — открыть `.md` в новой вкладке; обычный клик навигирует текущую).
      При переносе вкладки между окнами сигналы **переподключаются** в
      `MainWindow._adopt_view` (`disconnect` + `connect`), сам виджет не
      пересоздаётся, поэтому состояние едет целиком.
    - **tear-off/merge.** `TabBar.mouseMoveEvent` запускает `QDrag` только когда
      указатель вышел за **рамку всего окна** (`frameGeometry`), а не за тонкую
      полосу: иначе вкладка отрывалась при малейшем уходе вниз и обычная
      перестановка (`setMovable`, которую Qt делает в `super().mouseMoveEvent`)
      становилась невозможной. Payload — `TAB_MIME` + `_TabMimeData.view`;
      `_resolve_drag_view` падает на module-global `_DRAG_VIEW`, т.к. Qt может
      отдать базовый `QMimeData` без Python-подкласса. Когда полоса дроп не
      приняла, `_resolve_tab_drop` решает по `_window_at(QCursor.pos())`:
      чужое окно → merge (`_take_view` + `_adopt_view`, окно поднимается);
      своё окно → ничего; вне всяких окон → `_tear_off` (новое окно в точке
      курсора, `_take_view` с `setParent(None)`). Drop точно на чужую полосу
      обрабатывает `TabBar.dropEvent`; окно-источник закрывается, если вкладок
      не осталось.
    - **Единственный экземпляр (`instance.py`).** Windows запускает новый процесс
      на каждый двойной клик по `.md`. `main.py` берёт mutex
      `Local\MDViewer-singleton`; второй процесс пишет пути в
      `%LOCALAPPDATA%\MDViewer\requests\*.req` и выходит, а owner опрашивает
      очередь (`instance.RequestWatcher`, 400 мс) и открывает их вкладками
      (`MainWindow.open_external`, окно поднимается). `QtNetwork`/`QLocalServer`
      недоступны (вырезаны спеком) — отсюда stdlib-подход. `MDVIEWER_STATE_DIR`
      переопределяет каталог очереди (для тестов).
    - **Сессия.** Флаг `QSettings("restore_session")` (по умолчанию выключен),
      снимок — `session_paths` + `session_active` (`_save_session` всех окон из
      реестра `_WINDOWS`), восстановление — `_restore_session`. Тумблер — ПКМ по
      полосе вкладок (`_show_tab_menu`), CLI — `--restore-session`. Открытие
      файлов идёт через `MainWindow._open_paths`/`_add_tab`/`_open_files_dialog`.
    - **Совместимость `tools/`.** `tools/edit_check.py` и `render_check.py`
      используют `viewer.Viewer(path, settings)` (подкласс `MainWindow`) и
      проксирование `MainWindow.__getattr__`/`__setattr__` в текущий `DocumentView`.
      Не ломать: инструменты обращаются к атрибутам окна напрямую.
    - **Переоткрытие и зум.** `Ctrl+Shift+T` возвращает последнюю закрытую вкладку:
      модульный стек `_CLOSED_TABS` (кэп `_CLOSED_LIMIT`=20) кладёт `_close_tab`
      после `_confirm_discard`; merge/tear-off и закрытие окна в стек не пишут.
      Клик по метке зума — `100%` → `200%`, иначе → `100%`
      (`_toggle_zoom_label`, `_toggle_editor_zoom_label`; `_reset_zoom` остаётся
      жёстким сбросом для `Ctrl+0`). `QSettings("default_zoom")` (уровень,
      по умолчанию 0) заставляет `_add_tab` открывать новые вкладки на этом
      масштабе; выбор — подменю «Масштаб по умолчанию» в ПКМ-меню вкладок
      (`_set_default_zoom`, применяется и к текущей вкладке).
    - **ПКМ-меню вкладок** (`_show_tab_menu`) действует на вкладку под курсором
      (`tabBar().tabAt(pos)`, при `-1` — активная): «Открыть содержащую папку» и
      «Копировать путь» (только локальные пути, инвариант 5), а также подменю
      «Недавние» — список `QSettings("recent_files")` (свежие впереди, без
      дублей, только существующие файлы, кэп `viewer.RECENT_LIMIT`=10). Список
      пополняет модульный `remember_recent_file` из `_add_tab` и
      `DocumentView._load_path` (навигация по ссылке/«Назад»).

27. **Режим чтения (F11), крошки и фильтр оглавления.**
    - **Режим чтения** — оконный хоткей `F11` в
      `MainWindow._build_window_shortcuts` → `_toggle_reading_mode`:
      `showFullScreen()`, полоса вкладок `_tabs.tabBar().setVisible(False)`, у
      активного `DocumentView` `_set_reading_mode(True)`. Тот прячет оглавление,
      запомнив `_toc_user_visible` в `_reading_toc_saved`, и подавляет оверлей
      (`_show_overlay` выходит при `_reading_mode`). Выход — повторный `F11` или
      `Esc`; `Esc` разобран в `DocumentView._handle_esc`: если host в режиме,
      сначала выйти (автопрокрутку/поиск не трогать). `toc_visible` в QSettings
      не пишется — режим временный. В правке (`_editing()`) оглавление и панель
      редактора **не двигаются**: `_set_reading_mode` трогает `_toc_*` только
      вне правки (раскладка по инварианту 25 не ломается).
    - **Крошки** — `QLabel#breadcrumbs` над `_browser`, а сам браузер обёрнут в
      `_preview_panel` (`QVBoxLayout`: крошки + браузер). В сплиттер добавлен
      контейнер, а не браузер, поэтому детей по-прежнему три (оглавление /
      превью-контейнер / редактор) и все ссылки на `self._browser`
      (`_pane_for`, `_set_margins`, `_place_overlay`, eventFilter на viewport)
      работают. Путь собирается `_crumb_path` из `self._outline` по
      `_current_section_index()` (предки — ближайшие заголовки со **строго**
      меньшим `level`), сегменты — `<a href="{row}">` (индекс строки, не текст!)
      и разделитель `›`, HTML экранируется, длинные обрезаются
      (`CRUMB_LABEL_MAX`/`CRUMB_SEGMENT_MAX`). Клик — `_crumb_clicked` →
      `_outline_clicked`. Строка видна только при ≥2 сегментах. Обновляется из
      того же `valueChanged`, что и оглавление, **отдельным** `_sync_crumbs`
      (в `_sync_outline` нельзя: он рано выходит при скрытом оглавлении), а
      также после `_render`, `_outline_clicked` и `_set_zoom`.
    - **Фильтр оглавления** — `QLineEdit#tocFilter` над `_toc` в `_build_outline`;
      само оглавление теперь в панели `_toc_panel`, и `_relayout`,
      `_on_splitter_moved`, `_toc_can_toggle` смотрят на панель (не на `_toc`).
      `textChanged` → `_apply_toc_filter`: `setHidden` несовпадающих
      (регистронезависимо), при вводе панель при необходимости показывается.
      `Esc` в поле очищает фильтр (ветка в `eventFilter` **и** в `_handle_esc`).
      `_populate_outline` переприменяет текущий текст фильтра. `_build_outline`
      создаёт `_toc` до добавления фильтра в layout, а `_pane_for` берёт панели
      через `getattr`: событие может прийти во время сборки виджетов, иначе
      `AttributeError` в `eventFilter` роняет процесс с `0xC0000409`.

28. **Редактор: необязательные перенос строк и номера строк.**
    Настройки `QSettings("editor_wrap")` (дефолт — вкл) и
    `QSettings("editor_line_numbers")` (дефолт — выкл) переключаются кнопкой
    «⋯» в шапке панели редактора и применяются сразу и к текущему, и к будущим
    редакторам (`_apply_editor_options` при `_build_editor`). Перенос —
    `QPlainTextEdit.setLineWrapMode(WidgetWidth|NoWrap)`. Номера строк —
    классический жёлоб `LineNumberArea` в отступе `QPlainTextEdit`; место
    резервирует `setViewportMargins`, поэтому он не перекрывает текст.
    `LineNumberedEdit` наследует `OverlayPlainTextEdit`, то есть
    `_OverlayMixin.paintEvent` (ручная дорисовка зеркала выделения поверх
    нативного, инвариант 22) продолжает работать: жёлоб — **отдельный дочерний
    виджет**, а не часть `paintEvent` редактора. Не рисуй зеркало в жёлобе и не
    трогай     `_paint_selection_overlay`. Тумблеры не меняют `toPlainText()`
    (по-прежнему только `\n`, инвариант 10) и базовую линию `_baseline`.

29. **Каждый `DocumentView` следит за своим файлом** (`QFileSystemWatcher`, один
    вид — один файл). `_watch` — текущий наблюдаемый путь; `_watch_current()`
    вызывается в конце удачного `load()`, поэтому навигация (`_navigate`,
    `_go_back`, клик по ссылке) и `F5` переставляют наблюдение на новый путь, а
    `_watcher` — дочерний виджет, поэтому снимается вместе с представлением.
    Уведомления дебаунсятся `_reload_timer` (`FILE_WATCH_DEBOUNCE_MS` = 200 мс,
    single-shot): редакторы пишут temp+rename, и одна запись приходит пачкой;
    после **каждого** события `_rewatch()` заново снимает и ставит путь (на
    Windows наблюдение слетает при атомарной замене). Логика перезагрузки
    вынесена в `_on_file_changed()` (решённое) и `_reload_from_disk()`
    (чтение+перерисовка), их тесты дёргают напрямую — без реального ФС. Без
    несохранённых правок (`_is_unsaved()`) файл перечитывается молча, с
    сохранением символа на верхней кромке (`_scroll_preview_to`, как при
    `load`/зуме); с правками — `QMessageBox` Да/Нет. Сравнение «файл
    изменился» идёт с `_text` (что на диске), а не с `_rendered`: превью может
    показывать черновик после «Конвертировать». Пропавший/переименованный файл
    не трогает содержимое и просто снимает наблюдение. Перезагрузка — тот же
    документ и та же вкладка, а не новая (не ломает single-instance/сессию).
    Любая перерисовка здесь — по событию ФС, а не на `valueChanged` (инвариант 12).

30. **Поиск с заменой живёт в редакторе (`Ctrl+H`).** Per-document хоткей
    `Ctrl+H` (`WidgetWithChildrenShortcut`, рядом с `Ctrl+F`) зовёт
    `_toggle_replace`/`_open_replace`: если редактора нет, сначала
    `_enter_edit()`, затем показывается строка «Заменить на» — часть той же
    ленивой панели `_find_bar` (второй ряд, `_replace_row`, по умолчанию
    скрыт). `Ctrl+F` её прячет (`_set_replace_mode(False)`), `Esc` в поле
    замены закрывает панель (`_handle_esc`). Замена работает только по
    `self._editor` (`QTextDocument.find`): `_replace_next` меняет совпадение,
    только если выделение и есть текущий матч, и уводит поиск к следующему;
    `_replace_all` сначала собирает диапазоны, потом меняет их **с конца**, и
    возвращает число замен (уведомление — в `_find_status`, без модальных
    окон). Пустой паттерн (`_search_pattern` → `None`) — no-op. Правки идут
    через `textChanged`, поэтому dirty и карта помечаются существующим путём
    (`_update_state`/`_map_dirty`), а превью не перерисовывается (инвариант 12).

31. **Синхронизация прокрутки редактор ↔ превью — только в правке.** Тумблер
    `QSettings("sync_scroll")` (дефолт — вкл) в меню «⋯» редактора
    (`_build_editor`). `valueChanged` обоих `verticalScrollBar` зовёт
    `_queue_scroll_sync`, которая взводит `_sync_timer` (`SYNC_SCROLL_MS` = 70,
    single-shot) — троттлинг пачки шагов. `_sync_scroll_now` применяет одно
    перемещение через карту `SourceMap` (`to_source`/`to_render`), а если карта
    недоступна/устарела (`_map_dirty`) — по заголовку раздела
    (`_editor_position_for_section` / `_editor_section_label` +
    `_preview_index_for_label`), **не пересобирая HTML**. Петля рвётся флагом
    `_syncing_scroll`: установка чужого скроллбара эмитит `valueChanged`, но
    очередь при поднятом флаге выходит. Синхронизация не идёт вне правки, при
    скрытой панели, при `_in_relayout` и выключенном тумблере. Вход/выход из
    правки поднимают `_sync_suppressed` (`SYNC_SCROLL_SETTLE_MS` = 250, затем
    `_release_scroll_sync`), иначе расстановка каретки/`_relayout` сами дёргали
    бы прокрутку и «прыгали» (инварианты 15/17). `_scroll_editor_to` кладёт
    `blockBoundingGeometry(block).top()` прямо в скроллбар: у `QPlainTextEdit`
    он измеряется в пикселях, а геометрия блока — в координатах документа.

Максимум контента — до `MEASURE` px, оглавление фиксируется по `TOC_WIDTH`,
отступы уровней — `TOC_STEP`; всё в `theme.py`.
