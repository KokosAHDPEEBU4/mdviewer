## Что за проект

Настольный просмотрщик Markdown для Windows: превью (QTextBrowser) +
оглавление + панель правки исходника (QPlainTextEdit), оверлей управления,
поиск, зум, взаимная подсветка выделения. Подробности и инварианты — `AGENTS.md`.

## Состояние на конец сессии

Сделано и проверено (тесты `tools/edit_check.py`, `tools/render_check.py` — зелёные):

- Точный зум «100%», плавный `Ctrl+колесо` (накопление дельты).
- Код-блоки больше **не** таблицей, а `<pre class="code-body">` (`text-indent`) —
  иначе Qt ломает выделение в таблице-карточке.
- Ссылки на `.md` открываются в окне, есть кнопка «Назад»/`Alt+Left`.
- Политика сжатия окна: `layout_panes` + авто-скрытие оглавления с гистерезисом.
- Взаимная подсветка: карта позиций `syncsel.SourceMap` + **custom-paint поверх**
  (см. «грабли»); цвета — оранжевый превью, бирюзовый редактор.
- Открытие правки — на подглаве, без сдвига превью; окно растёт по экрану, где окно.
- Широкая ручка сплиттера (14 px) + подсветка.

Незакоммичено: все правки сессии в рабочем дереве (`git status`/`git diff`);
коммитов в этой сессии не делали, только `build.bat` + `--install-default`.

## Проверенные факты и грабли (важно для следующей сессии)

- **Qt рисует нативное выделение ПОВЕРХ `extraSelections`** (проверено
  рендером; z.ai утверждал обратное — неверно для Qt 6.11). Поэтому зеркало
  подсветки рисуется вручную в `paintEvent` после `super()` (`_OverlayMixin`,
  `_paint_selection_overlay`, `HL_OVERLAY_ALPHA`). Не пытаться «поверх» через
  `setExtraSelections`.
- `QSplitter.setSizes` индексирует **всех детей, включая скрытых** — список
  всегда полный (0 для скрытой панели), иначе ширины уйдут не туда.
- Курсор выделения, пересекающий ячейки таблицы, Qt расширяет до целых ячеек —
  диапазоны режем **по блокам** (`_range_cursors`/`_own_cursors`).
- Панель редактора содержит строку кнопок ~450 px: обязателен
  `_panel.setMinimumWidth(EDITOR_HARD)`, иначе минимум протекает в сплиттер.
- `toPlainText()`-индексы совпадают с позициями документа (кроме нюанса с
  таблицами — см. по-блочную нарезку). Карта `syncsel.SourceMap` строит
  соответствие источник↔рендер по словам.
- Версия — диагностика: сборку и установку проверять сравнением sha256
  `dist\MDViewer` и `%LOCALAPPDATA%\Programs\MDViewer` (AGENTS, инварианты 7/13).

## Команды

```
.venv\Scripts\python main.py README.md        # запуск из исходников
.venv\Scripts\python tools\edit_check.py      # правка/зум/подсветка/раскладка
.venv\Scripts\python tools\render_check.py    # тема
.venv\Scripts\python -m py_compile *.py
build.bat                                      # сборка dist\MDViewer
.venv\Scripts\python main.py --install-default --no-prompt   # установить
```

## Окружение / мониторы (учитывать!)

- Два экрана: `U1` 3440×1440 @ (0,0) — **primary**; `HDMI` 2560×1440 @ (−2560,0).
- Окна тестов **не поднимать на `U1`** (ультравайд). Запускать тесты с
  `MDVIEWER_TEST_SCREEN=secondary` — инструменты кладут окна на `HDMI`.
- Установка/сборка — headless, окна не открывают. Перед install закрыть
  запущенный MD Viewer (иначе `WinError 32`), затем чистая переустановка
  (`Remove-Item` папки + `--install-default --no-prompt`).
