# Панель «Файлы папки» — архитектура (обсуждение, целевая версия 2.9.0)

> Статус: черновик на согласование. HTML-мокап **согласован**
> (`tree_panel_mockup.html`). Ответы на вопросы — в `tree_panel_questions.md`;
> до их получения код не меняется.

## 1. Модель в двух словах

**Панель = навигация внутри одной папки, вкладки = «закреплённые» файлы из
разных папок.**

Панель «Файлы папки» живёт слева от оглавления на уровне окна, показывает
файлы каталога активной вкладки и по умолчанию скрыта. Переключение вкладки
на файл из другой папки молча меняет содержимое панели на папку того файла.
Файл из панели можно перетащить на полосу вкладок — он «закрепится» вкладкой
и переживёт переключение панели на другие папки.

## 2. Сценарии использования

1. **Чтение папки.** Открыли `инструкция.md` → включили панель (хоткей или
   пункт меню) → щёлкают соседние `.md` — каждый открывается в текущей
   вкладке с историей «Назад» (Alt+Left работает). Вкладки не плодятся.
2. **Сборка рабочего набора.** Из панели тащат 2–3 файла на полосу вкладок —
   те открываются вкладками в позиции курсора. Дальше панель свободно
   используют для просмотра — закреплённые файлы не теряются.
3. **Мультипапочный режим.** Открыты вкладки из трёх папок. Переключение
   между ними меняет содержимое панели — каждая папка «под рукой» без дерева
   каталогов.
4. **Возврат к чистому виду.** Режим чтения (F11) прячет панель вместе с
   полосой вкладок; выход возвращает. Тумблером панель убирается совсем;
   видимость и ширина запоминаются.

## 3. Архитектура

### 3.1. Уровень панели — окно, не вкладка

Панель живёт на уровне `MainWindow`, а не `DocumentView`. Обоснование:
вкладка = целый `DocumentView`, при переключении вкладок виджет внутри
вкладки полностью меняется. Панель внутри `DocumentView` пересоздавалась бы
на каждую вкладку, дублировала наблюдение за диском и сбивала правило
«один вид — один файл» (инвариант 26). Оконная панель одна, за активной
вкладкой следует по сигналу `currentChanged`.

### 3.2. Компоновка окна

```
сейчас:   central = QTabWidget
станет:   central = QSplitter(горизонтальный)
            ├── #treePanel  «Файлы папки» (скрыта по умолчанию)
            └── QTabWidget  (без изменений)
                  └── DocumentView (его внутренний сплиттер
                       [оглавление | превью | редактор] не трогаем)
```

Панель отнимает ширину слева; внутренний `_relayout` `DocumentView`
подхватывает это сам через уже существующий eventFilter на Resize
(инвариант 25) — специальных связей не нужно.

### 3.3. Состав панели

- Шапка: подпись «Файлы папки», имя текущей папки, кнопка «✕» (скрыть).
- Список файлов (v1 — `QListWidget`, как оглавление; плоский список ровно
  одной папки, без подкаталогов).
- Строки: папка/иконка/имя; просматриваемые (`.md/.markdown/.txt`) обычным
  цветом, прочие приглушённо; активный файл подсвечен; файлы, уже открытые
  во вкладках окна, помечены точкой «•»; тултип строки — полный путь.
- Фильтр, дерево вложенности, зум, «вверх» — v2 (см. вопросы).

### 3.4. Поток данных

| Событие | Реакция |
|---|---|
| `currentChanged` (переключение вкладки) | `_sync_tree_folder()`: папка изменилась → перечитать `iterdir()`, отсортировать (папки вперёд, натуральная сортировка имён без учёта регистра), отрисовать, подсветить активный файл и открытые во вкладках |
| Клик по viewable-файлу | `_navigate` (текущая вкладка, история «Назад») или `_add_tab` (новая; дедуп по `Path.resolve()` уже существует) |
| Ctrl+клик / средняя / двойной | `_add_tab` — новая вкладка |
| Клик по не-viewable | `QDesktopServices.openUrl` (инвариант 5) |
| Drag строки → полоса вкладок | `QDrag` с `FILE_MIME` (+ module-global фолбэк по образцу `_DRAG_VIEW`); `TabBar.dropEvent` → `_add_tab` по индексу курсора |
| Файлы в папке изменились | `QFileSystemWatcher` на папку + single-shot дебаунс 200 мс (паттерн инварианта 29: `FILE_WATCH_DEBOUNCE_MS` + `_rewatch` после каждого события); тихая перерисовка с сохранением прокрутки/выделения |
| Тумблер панели | показать/скрыть; persist `tree_visible`, ширина — `tree_width` (по образцу `toc_visible`/`toc_width`) |
| Режим чтения F11 | панель прячется вместе с полосой вкладок, выход возвращает |

## 5. Подводные камни

- **Инвариант 20 в новом виде.** `setSizes` оконного сплиттера индексирует
  **всех** детей, включая скрытых: список размеров всегда полный (0 для
  скрытой панели), иначе ширины поедут не туда.
- **Инвариант 26 повторить для файлов.** Qt может отдать в dropEvent базовый
  `QMimeData` без Python-подкласса — путь перетаскиваемого файла
  дублируется module-global `_DRAG_FILE`.
- **Watcher-шторм.** Windows шлёт пачку событий на каждую операцию; без
  дебаунса панель перечитывается десятки раз при одном `_save` (temp+rename).
  После каждого события — `_rewatch` (наблюдение слетает при атомарной
  замене, инвариант 29).
- **Не дёргать рендер.** Показ панели меняет геометрию превью → документ
  переразбивается, но это существующий путь `_relayout` + `_set_margins` +
  якорь верхней кромки; новых перерисовок HTML нет (инвариант 12).
- **`MIN_WINDOW_WIDTH`** считается из трёх внутренних панелей; при видимой
  панели файлов минимум окна должен учитывать `TREE_MIN_WIDTH`, иначе
  safety net раздавит панель.
- **`iterdir` может упасть** (сетевой диск, права, длинные пути) —
  `try/except` + подпись «папка недоступна» вместо тихой пустоты.
- **Фокус.** Кнопки панели — `NoFocus`; после открытия файла фокус
  возвращается превью.
- **Инвариант 18.** Тултипы с полным путём можно; тултипов с хоткеями — нет.
- **Натуральная сортировка** (`файл2 < файл10`), кириллица через `casefold`.
- **Переименование текущего файла извне** — вкладка переживает это уже
  сейчас (инвариант 29); панель просто перечитает папку.
