## 1. Вкладки (tabs) — как в браузере

[ ] Развилки утверждены (см. 1.7), можно реализовывать.

### 1.1 Что нужно

- Вкладки сверху, **без кнопки «+»** для создания пустой вкладки. Новые вкладки
  появляются только из открытых файлов (CLI, `Ctrl+O`, переходы по ссылкам).
- Вкладки **переставляются местами** перетаскиванием.
- Вкладку **можно вытащить в отдельное окно** (tear-off), и, в идеале, вкладку
  можно перетащить в другое окно приложения (слияние окон).
- Логика браузерная, но без «новых вкладок»: одна вкладка = один файл;
  повторное открытие уже открытого файла фокусирует существующую вкладку.

### 1.2 Что есть сейчас (контекст)

- `main.py` создаёт по одному `Viewer(path).show()` на файл — **одно окно на файл**.
- `Viewer(QMainWindow)` держит всё состояние одного файла: сплиттер
  (оглавление/превью/редактор), оверлей, поиск, зум (превью/редактор/оглавление),
  правка, взаимная подсветка, карта позиций, история «Назад», dirty-state,
  `QSettings`, геометрию окна, тёмный заголовок.

### 1.3 Архитектура (предлагаемая)

Разделить «окно» и «документ»:

- `DocumentView(QWidget)` — содержимое одного файла (всё, что сейчас внутри
  `Viewer`, кроме оконных дел). Создаётся один на вкладку, состояние изолировано.
- `MainWindow(QMainWindow)` — оболочка: `QTabWidget`, заголовок окна, геометрия,
  хоткеи уровня окна, реестр окон для tear-off/merge.

Рефакторинг `Viewer` (QMainWindow → QWidget): перенести в `MainWindow`
`setCentralWidget` (центральный виджет — `QTabWidget`), `setWindowTitle`/`_title`,
`resize`/`restoreGeometry`, `closeEvent`, `showEvent` (DWM тёмный заголовок),
`_view_geometry`. `_enter_edit` менять не сильно — ресайз теперь на `MainWindow`
(растёт всё окно, высота вкладок учтётся автоматически).

### 1.4 Вкладки: виджет и поведение

- `QTabWidget`: `setTabsClosable(True)`, `setMovable(True)`,
  `setDocumentMode(True)`. **Corner-widget с «+» не добавляем.**
- Страница вкладки — `DocumentView`. Подпись = имя файла (`path.name`) + ` •` при
  несохранённых изменениях; tooltip = полный путь.
- Дедуп: `Path.resolve()` → если файл уже открыт, переключиться на вкладку.
- `Ctrl+O` (`getOpenFileNames`, множественный выбор) → по вкладке на файл.
- `Ctrl+W` (и кнопка `×`, и средний клик по вкладке) → закрыть вкладку с
  `_confirm_discard`; если вкладок не осталось — закрыть окно.
- **Ссылки на другие `.md` — как в браузере:** обычный клик навигирует **текущую**
  вкладку (работает история «Назад»), `Ctrl`+клик и средняя кнопка — открывают
  **новую** вкладку. Править `viewer._open_link`: пробрасывать модификатор клика
  (в `anchorClicked` его нет — брать по `QApplication.keyboardModifiers()` или
  ловить клик в `_OverlayMixin`/`mouseReleaseEvent`).
- `main.py`: один `MainWindow`; все CLI-пути — вкладками. Если файлов нет —
  диалог; после диалога пусто — выход.
- `QApplication.setQuitOnLastWindowClosed(True)` (сейчас одна вкладка = окно).

### 1.5 Перестановка и вытаскивание

- Перестановка — готовое `setMovable(True)` (`QTabBar.tabMoved`). Сохранять
  порядок в `QSettings` (см. 1.7).
- Tear-off **и** merge окон — делаем оба. `QTabBar` нативно не умеет → подкласс
  `TabBar(QTabBar)`:
  - `mousePressEvent` запоминает индекс; `mouseMoveEvent` при выходе за полосу
    запускает `QDrag` с mime `application/x-mdviewer-tab` (payload: ссылка на
    `DocumentView` или id окна+индекс);
  - `setAcceptDrops(True)`, `dragEnterEvent`/`dropEvent` на `TabBar`;
  - drop **вне** любой полосы → новый `MainWindow` в точке курсора, вкладка
    переносится туда; drop **на** чужую полосу → перенос между окнами (слияние);
  - при переносе: `removeTab(index)` возвращает виджет, `setParent(None)` и
    `addTab` в целевом `QTabWidget`; состояние (текст, dirty, зум, история,
    `_hl_layers`, `_source_map`) уже внутри `DocumentView` — переносится целиком;
  - окно-источник закрывается, если вкладок не осталось.
  - Реестр окон — через `QApplication.topLevelWidgets()` или явный список.

### 1.6 Хоткеи, заголовок, состояние

- `Ctrl+Tab`/`Ctrl+Shift+Tab` — соседняя вкладка; `Ctrl+1..9` — по номеру.
- Текущие хоткеи (`Ctrl+E/F/B`, `Ctrl+= / - / 0`, `F5`, `Alt+Left`, `Ctrl+S`,
  `Ctrl+Enter`) должны бить по **активной** вкладке: перенести в `DocumentView`
  или маршрутизировать из `MainWindow` в текущий.
- Заголовок окна = заголовок активной вкладки (`_title`), `•` — из активной.
- Что хранится где (утверждено):
  - **глобально** (один `QSettings` на приложение): включённость/ширина панелей
    (`toc_visible`, `toc_width`), порядок вкладок, настройка восстановления сессии;
  - **на вкладку** (`DocumentView`): зум превью/редактора/оглавления и взаимные
    подсветки/выделения — уже изолированы, дополнительно сохранять не нужно
    (или, при желании, по `path`);
  - геометрия окна — на окно, как сейчас.
- `closeEvent` окна проверяет несохранённые **во всех** вкладках.
- **Восстановление сессии** — опция: флаг `QSettings("restore_session", False)`.
  При включении на старте открываются вкладки прошлой сессии (список путей +
  активная). По умолчанию выключено. Тумблер: пункт в контекстном меню по
  вкладкам (`TabBar`/`QTabWidget`) или CLI-флаг `--restore-session`.

### 1.7 Решения (утверждено 2026-10-04)

- **Ссылки между `.md`:** как в браузере — обычный клик навигирует текущую
  вкладку (с историей «Назад»), `Ctrl`+клик / средняя кнопка — новая вкладка.
- **Слияние окон:** делаем `tear-off` **и** `merge` (перетаскивание вкладки в
  другое окно приложения).
- **Восстановление сессии:** опция в настройках (`restore_session`, по умолчанию
  выключено); при включении — открывать вкладки прошлой сессии.
- **Хранение настроек:** глобально (порядок/ширина/включённость панелей, порядок
  вкладок, флаг сессии); зум и выделения — **на каждую вкладку** самостоятельно.

### 1.9 Тесты

- `main.py a.md b.md` → одно окно, две вкладки.
- `Ctrl+O` добавляет вкладки; повторное открытие файла фокусирует существующую.
- Перестановка вкладок (`setMovable`/`tabBar().moveTab`).
- Закрытие вкладки с несохранённым → диалог; закрытие последней → окно/процесс.
- Tear-off (эмуляция drag) → новое окно с тем же `DocumentView`, состояние цело.
- Изоляция: зум/правка/история/подсветка не «текут» между вкладками.
- Добавить `tools/tabs_check.py`; дополнить `tools/edit_check.py`.

### 1.10 Риски

- Рефактор `QMainWindow` → `QWidget` крупный: в `Viewer` много оконных обращений
  (`_title`, geometry, `showEvent`/DWM, `enterEvent` оверлея, `resizeEvent`,
  `closeEvent`, `_view_geometry`).
- Tear-off/merge — самое рискованное: reparent виджетов, drag&drop, закрытие
  окон, подсчёт ссылок.
- Не сломать уже проверенное (правка, зум, подсветка, «Назад» — тесты в
  `edit_check.py`).
